# WealthCodeX skill

This is Aarohi's first specialist skill, not the definition of Aarohi itself.

## Scope

- Hinglish (Roman script), 45–60 second videos
- Cinematic documentary identity
- Content mix: 50% gaming industry/economics, 30% AI/emerging technology, 20% business/innovation
- One consistent fictional female virtual presenter and female Hinglish voice
- One master video with platform-specific metadata and publishing adapters
- Daily target, with failed quality/policy checks quarantined rather than bypassed

## Required workflow

Trend discovery → source research → claim verification → script → voice/presenter/assets → render → quality and licensing gates → platform-specific distribution → analytics.

## Publishing constraints

YouTube, Instagram, Facebook, X, TikTok and LinkedIn are separate adapters. Each must be enabled only after its API access, account eligibility and permissions are verified. Do not assume all platforms are immediately available.

## Integration status

Specification only. The original WealthCodeX Phase 1 starter code has not yet been migrated into Aarohi. No publishing credentials or schedules are configured.
